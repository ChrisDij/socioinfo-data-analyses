# SocioInfo Data Analyses

Two R/Quarto analysis projects demonstrating data cleaning, exploratory analysis, visualisation and evidence-based reporting.

## Customer segmentation in retail

Explores purchasing behaviour using recency, frequency, monetary value and product-diversity measures.

- [Quarto source](./Project1/customer-segmentation.qmd)

## Olympic Games performance

Analyses hosting, medal performance, participation and gender trends from 1896–2022.

- [Quarto source](./Project2/olympic-performance.qmd)

## Requirements

- R and Quarto
- `tidyverse`, `ggplot2` and `readxl`

To render a report, place the original source datasets beside its `.qmd` file and run `quarto render <file>.qmd`.

## Limitations and academic context

The datasets were not present in the recovered directories, so these sources are not currently reproducible without reacquiring the data. Submitted PDFs and student-number identifiers are excluded. This is historical Stellenbosch University coursework and carries no open-source licence.
